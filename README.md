# 📊 SQL-DB: 관계형 데이터베이스 설계 및 분석 실습

이 저장소는 **Codyssey AI All-in-One** 과정의 미션 12 과제를 수행하기 위한 공간입니다. 엑셀과 차별화되는 데이터베이스의 '관계'와 '무결성'을 이해하고, SQL을 통해 실무적인 비즈니스 지표를 도출하는 것을 목표로 합니다.

## 🚀 프로젝트 개요
- **주제**: 도서 대여 관리 시스템 (Library Management System)
- **도구**: SQLite 3.43.2
- **핵심 목표**: 
  - 4개 이상의 테이블 설계 및 1:N 관계 구축
  - 참조 무결성(FK) 제약조건 적용 및 검증
  - JOIN, GROUP BY, 서브쿼리를 활용한 복합 데이터 분석

---

## 🛠 데이터 모델링 (ER-Diagram)


### 테이블 구조
1. **members (회원)**: 사용자 정보 관리
2. **categories (카테고리)**: 도서 분류 체계
3. **books (도서)**: 도서 상세 정보 (카테고리 1:N 관계)
4. **rentals (대여)**: 대여 및 반납 기록 (회원-도서 1:N 관계)

---

## 📁 파일 구성
- `schema.sql`: 테이블 생성 및 제약조건 정의 (CREATE TABLE)
- `data.sql`: 각 테이블당 10행 이상의 샘플 데이터 (INSERT)
- `queries.sql`: 실무 요구사항 해결을 위한 15개의 핵심 쿼리
- `images/`: 실행 결과 스크린샷 및 ERD

---

## 🔍 주요 학습 포인트 (보너스 과제)

### 1. JOIN vs 서브쿼리 비교
- 동일한 요구사항(특정 도서를 빌린 회원 조회)을 두 가지 방식으로 구현하여 실행 계획과 가독성 차이를 분석했습니다.

### 2. 데이터 정합성 검증 (FK 에러 테스트)
- 존재하지 않는 `member_id`를 가진 대여 기록 입력을 시도하여, 데이터베이스 엔진이 어떻게 데이터 무결성을 보호하는지 확인했습니다.

### 3. 미니 리포트 (핵심 지표)
- **인기 도서 TOP 3**: 대여 횟수 기준 상위 도서 추출
- **비인기 카테고리 분석**: 대여율이 낮은 카테고리 파악을 통한 도서 비치 전략 수립
- **우수 회원 리스트**: 대여 빈도가 높은 상위 3명의 회원 식별
